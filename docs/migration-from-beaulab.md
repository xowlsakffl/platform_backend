# Beaulab에서 Medi로 이관할 때의 기준

작성 기준: 2026-07-28

## 1. 전제

기존 Beaulab 백엔드는 Laravel 기준입니다. Medi 백엔드는 Spring Boot 기준으로 새로 구현합니다.

같게 가져갈 것은 코드가 아니라 아래 항목입니다.

- 도메인 개념
- 상태값
- API 흐름
- 운영 정책
- 권한 구조
- DB 관계와 제약

## 2. 우선 이관 대상

1차 백엔드 범위는 다음 도메인입니다.

- 계정: user, staff, hospital
- 병원
- 의료진
- 카테고리/해시태그
- 병원 입점신청
- 병원 이벤트
- 이벤트 상담 DB
- 리얼모델 신청
- 미디어
- 운영 히스토리

후순위 범위:

- 토크
- 후기
- 댓글
- 신고
- 채팅
- 알림 고도화
- 광고 캘린더
- 뷰티샵 도메인

## 3. 이관 시 금지 사항

- Laravel Action/Query/Policy 구조를 Java 패키지에 그대로 복제하지 않습니다.
- DB 테이블명에 `medi`를 붙이지 않습니다.
- API 경로에 `/medi`를 넣지 않습니다.
- 화면 표시용 브랜드명을 코드 곳곳에 하드코딩하지 않습니다.

## 4. 문서 사용법

기존 `docs/beaulab-reference` 폴더는 제거했고, 그 안의 문서는 `docs/`의 활성 문서로 승격했습니다.

Spring Boot 구현 시에는 반드시 다음을 다시 판단합니다.

- 이 기능이 1차 MVP에 필요한가
- 상태 전이가 현재 사업 모델에 맞는가
- 개인정보/의료광고 리스크가 반영되어 있는가
- 프론트 화면과 API 계약이 맞는가

세부 문서에 남아 있는 Laravel 경로와 클래스명은 구현 참고 맥락입니다. Medi에서는 도메인 규칙만 가져오고 구조는 Spring Boot 기준으로 다시 작성합니다.

## 5. 구현 순서

1. 공통 응답/예외/보안 설정
2. 계정과 인증
3. 병원/의료진/카테고리
4. 병원 이벤트
5. 상담 DB와 리얼모델 신청
6. 미디어 업로드
7. 운영 히스토리
8. OpenAPI 기반 프론트 API client 생성
